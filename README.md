# Hey Marketmate

MarketMate is an AI-powered autonomous marketing assistant for small businesses. It helps restaurants, salons, online shops, fitness studios, consultants and other small businesses plan and create marketing campaigns.

I want a modern, creative, premium-looking web application. Use a friendly but professional visual identity, with a dashboard, clear navigation and an intuitive user experience.

For now, create the initial application structure and interface. We will build the AI agent functionality in stages.
